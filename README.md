# JavaScript 2 - DOM - Lista de questões

## Como funciona

Cada questão tem dois arquivos com o mesmo número:

```
01.html   (abra no navegador: enunciado e área da questão)
01.js     (escreva o seu código aqui)
```

A **área da questão** (a caixa tracejada) tem elementos HTML. O seu código vai ler e mudar essa área.

1. Abra a pasta no VS Code e o `index.html` no navegador.
2. Clique na questão e abra o console (**F12**, aba **Console**).
3. Escreva o código no `.js`, salve e recarregue (**F5**).
4. Compare: clique em **"Ver como a área deve ficar no final"**. Quando a questão usa o console, a saída esperada aparece na própria página.

Não precisa mexer nos `.html` nem no `estilo.css`.
